# SHALOM

## 1. Sobre o projeto

O Palavra de Deus é uma plataforma cristã desenvolvida para partilhar conteúdos bíblicos, versículos e mensagens de fé.

## 2. Objetivos

- Partilhar a Palavra de Deus.
- Facilitar o acesso aos versículos bíblicos.
- Promover o conhecimento das Escrituras.

## 3. Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Node.js
- Base de dados
